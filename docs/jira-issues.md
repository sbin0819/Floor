# Jira 이슈 목록 (PFQV)

2026-10-07에 Jira에서 옮겨 적은 사본이다. 에이전트는 Jira에 접속하지 않으므로, 어떤 작업이 어느 이슈인지는 이 파일로 확인한다.

- 커밋 메시지에 해당 이슈 키를 붙인다. 예: `feat(db): add bookings exclusion constraint (PFQV-10)`
- 이슈의 상태 변경, 댓글, 설명 수정은 에이전트가 하지 않는다. 사람이 한다.
- 이 파일과 Jira가 다르면 Jira가 맞다. 다른 점을 발견하면 보고에 적는다.
- 구현의 기준은 이 목록이 아니라 `docs/spec/`의 명세와 `docs/codex/`의 작업 지시서다. 이 목록은 범위와 이름을 맞추는 용도다.
- "지시서" 열은 그 이슈를 다루는 작업 지시서다. 비어 있으면 아직 지시서가 없다.

일정은 16주다. 2026-10-05 시작, MVP 공개 2027-01-10, 포트폴리오 정리 완료 2027-01-24.
