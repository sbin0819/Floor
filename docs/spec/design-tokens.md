# 디자인 토큰

무드는 차분한 오피스 SaaS다. 화면은 대부분 무채색으로 두고, 색은 평면도의 공간 상태와 내 예약, 주요 버튼 하나에만 쓴다. 색이 곧 의미가 되게 한다.

화면 시안은 `docs/design/`에 있다. 시안의 글꼴은 IBM Plex Sans KR이지만 실제 앱은 Pretendard를 쓴다.

## shadcn/ui 변수 (라이트)

shadcn/ui의 CSS 변수에 아래 값을 넣는다. 컴포넌트는 이 변수로만 색을 쓴다.

| 변수 | 값 | 쓰임 |
| --- | --- | --- |
| `--background` | `#F7F7F5` | 앱 전체 바탕. 따뜻한 오프화이트 |
| `--foreground` | `#1C1C1A` | 본문 텍스트 |
| `--card`, `--popover` | `#FFFFFF` | 패널·카드·팝오버 표면 |
| `--card-foreground`, `--popover-foreground` | `#1C1C1A` | |
| `--primary` | `#3A5BD9` | 강조(인디고). 주요 버튼, 선택된 공간, 내 예약 |
| `--primary-foreground` | `#FFFFFF` | |
| `--secondary`, `--muted` | `#F1F0EC` | 회색 칩, 비활성 배경 |
| `--secondary-foreground` | `#4A4945` | |
| `--muted-foreground` | `#6B6A66` | 보조 텍스트 |
| `--accent` | `#EEF1FC` | 선택된 메뉴, hover 배경 |
| `--accent-foreground` | `#2B46AE` | |
| `--destructive` | `#9A4526` | 예약 취소, 내보내기 같은 되돌리기 어려운 동작의 글자색 |
| `--border` | `#E6E5E1` | 패널·카드 테두리 (1px, 그림자 없음) |
| `--input` | `#D6D4CD` | 입력창과 보조 버튼 테두리 |
| `--ring` | `#3A5BD9` | 포커스 링 |
| `--radius` | `8px` | 버튼·입력 8px. 카드는 12px |

shadcn이 요구하는 색 형식(oklch 등)이 다르면 같은 색으로 변환해서 넣는다.

## 추가 토큰 (공간 상태)

Tailwind에서 `bg-status-free`처럼 쓸 수 있게 테마에 등록한다. 상태는 색만으로 구분하지 않는다. 항상 글자나 아이콘을 같이 쓴다.

토큰 이름은 아래로 고정한다. 뒤 작업이 이 이름에 기댄다.

- `--status-{키}`: 배경
- `--status-{키}-foreground`: 글자
- `--status-{키}-border`: 테두리
- `--status-{키}-strong`: 진한 색 (범례의 점, 평면도 채움)
- 표에서 "–"인 칸은 토큰을 만들지 않는다.
- 점검 중의 빗금은 색이 아니라 그라디언트라서 `bg-status-maintenance-hatch` 유틸리티로 따로 만든다.

| 상태 | 키 | 진한 색 | 배경 | 테두리 | 글자 | 비고 |
| --- | --- | --- | --- | --- | --- | --- |
| 비어 있음 | `free` | `#2F9E7E` | `#E3F4EE` | `#B5E0D0` | `#1F6E57` | |
| 사용 중 | `busy` | `#D9734E` | `#FBEAE3` | `#EDC3B1` | `#8A3D20` | 미답변 문의 같은 경고에도 쓴다 |
| 선택 · 내 예약 | `mine` | `#3A5BD9` | `#EEF1FC` | `#3A5BD9` | `#2B46AE` | 드래그 중인 새 예약은 점선 테두리 |
| 점검 중 | `maintenance` | – | 빗금 | `#D6D4CD` | `#4A4945` | 빗금: 135도, `#F1F0EC`와 `#E6E5E1`을 8px씩 반복 |
| 전용 공간 | `restricted` | – | `#F1F0EC` | `#D6D4CD` | `#6B6A66` | 자물쇠 아이콘. 내가 쓸 수 없는 다른 팀 전용 공간 |
| 수락 대기 | `pending` | – | `#FAEEDA` | – | `#633806` | 초대 상태 배지 |

상태 판정 순서: 접근 불가(전용 공간) > 점검 중 > 사용 중 > 내 예약 > 비어 있음. "사용 중"은 다른 사람의 예약이 지금 진행 중일 때다. 내 예약이 지금 진행 중이면 "내 예약"으로 본다.

## 그 밖의 색

기능 화면에서 쓸 값이다. 셋업에서는 토큰으로 넣지 않는다. 표에 없는 shadcn 변수(`--chart-*`, `--sidebar-*` 등)는 shadcn 기본값을 그대로 둔다.

| 이름 | 값 | 쓰임 |
| --- | --- | --- |
| 이용률 4단계 | `#EEF1FC`, `#C9D3F5`, `#8FA3EA`, `#3A5BD9` | 운영자 히트맵. 낮음 → 높음 |
| 운영자 사이드바 | 배경 `#1C1C1A`, 선택 `#33332F`, 글자 `#D6D4CD` | 운영자 화면의 왼쪽 메뉴 |
| 팀 전환 레일 | 배경 `#ECEBE7`, 테두리 `#E0DFDA` | 맨 왼쪽 64px 열 |
| 구분선 | `#EFEEEA` | 표의 행 사이 |
| 비활성 글자 | `#A3A19B` | 지난 시간 슬롯 |
| 전송 중 말풍선 | 배경 `#C9D3F5`, 글자 `#1E2F74` | 서버 확인 전 메시지 |

## 타이포

- 글꼴: Pretendard, 대체 `system-ui, sans-serif`
- 굵기는 400, 500, 600만 쓴다.

| 용도 | 크기 / 굵기 |
| --- | --- |
| 페이지 제목 | 24 / 600, 자간 -0.01em |
| 제목 | 20 / 600 |
| 섹션 제목 | 16 / 600 |
| 본문 | 14 / 400 |
| 보조 | 12 / 400, 색 `--muted-foreground` |
| 평면도 라벨 등 작은 글자 | 11 |

시간과 숫자는 `font-variant-numeric: tabular-nums`로 자릿수를 고정한다.

## 간격, 모서리, 크기

- 간격은 4px 그리드
- 모서리: 버튼·입력 8px, 카드 12px, 배지·칩은 완전히 둥글게
- 컨트롤 높이: 기본 44px (버튼, 입력), 작은 것 36px, 탭·필터 칩 32px, 배지 24–26px. 44px보다 작은 컨트롤은 누를 수 있는 영역을 44px로 넓힌다
- 카드 안쪽 여백 20px, 페이지 여백 24–32px
- 그림자는 쓰지 않는다. 표면은 1px 테두리로 구분한다 (모바일 바텀시트만 예외)

## 모션

- 150–200ms, ease-out
- 예약이 생기면 평면도의 해당 공간이 살짝 펄스, 롤백되면 블록이 제자리로 되돌아간다 (기능 작업에서 구현)
- `prefers-reduced-motion`을 따른다

## 다크 모드

토큰 기반으로 같이 지원하는 것이 목표지만, 다크 색 값은 아직 정하지 않았다. 셋업에서는 `.dark` 구조만 두고 shadcn 기본 다크 값을 임시로 쓴다. 상태 토큰의 다크 값은 TODO로 남긴다.

## 셋업에서 넣을 컴포넌트

shadcn/ui: `button`, `badge`, `input`, `label`, `switch`, `tabs`, `tooltip`, `dialog`, `dropdown-menu`, `select`, `sonner`

직접 만드는 것 하나: `StatusBadge` — 위 표의 상태 6개(공간 상태 5개와 초대의 수락 대기)를 받아 배지를 그린다. Storybook 스토리를 같이 둔다.

버튼은 시안 기준 3종이다: 강조(`--primary` 채움), 보조(흰 배경 + `--input` 테두리), 글자만(위험 동작은 `--destructive` 글자색).
